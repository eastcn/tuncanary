## TunCanary 0.5.2

修复出口 IP 点击“检测”没有反应的问题，分离手动检测与自动采样。

- 自动检测继续按配置周期运行。手动点击立即发起请求，不等待自动间隔，也不推迟下一次自动检测。
- 每次手动检测结果写入本机历史，成功和失败都保留。连续检测及重启后再次手动检测均可入库。
- 检测中显示目标数量，完成后显示成功和失败数量；暂停、限流和取消也有明确反馈。
- 服务端 429 限流冷却和 403/挑战暂停仍生效，升级不会丢失旧历史中的限流状态。
- 设置说明和主页文案明确标注“自动检测间隔”，各目标详情继续独立展开/收起。

### 验证

468 个默认离线测试通过。实机连续手动检测两次，每次四个目标均成功，历史增加八条；自动检测计划未改变。发布流程再次执行离线测试，并校验版本号、签名和安装包校验值。

ZIP 包包含 ad-hoc 签名的 `TunCanary.app`，要求 macOS 13 或更高版本，包名注明架构。现有设置及本机历史保留。

## English

Fixes the exit IP check button appearing unresponsive when targets were inside the automatic sampling interval.

- Manual checks start immediately, save every result locally, and do not postpone scheduled automatic checks.
- Shows progress, completion counts, cancellation and reasons for unavailable checks.
- Preserves server rate-limit cooldowns, suspension and compatibility with previously saved rate-limit state.
- 468 offline tests passed. Two consecutive live manual checks added eight observations without changing the automatic schedule.

Requires macOS 13+. The ZIP contains an ad-hoc signed app and names its architecture. Existing settings and local history are preserved.
