## TunCanary 0.5.1

### 出口 IP 稳定性监测

- 自动检测默认每 5 分钟一次，可设为 5–1440 分钟；各目标错开请求，手动检测共用冷却。睡眠及网络切换宽限期暂停采样，遇到 429 退避，403 暂停自动检测。
- 按目标记录出口 IP、版本、地域和采样时间，统计 30 天内的变化及失败。IPv4、IPv6 分开比较；失败或采样间隙打断连续观察时段。历史仅保存在本机，保留 30 天，不进入诊断摘要或命令行 JSON。
- 海外目标使用 Cloudflare trace，新增字节检测 CDN 的 HEAD 响应头检测。自定义目标支持 Cloudflare 域名、HTTPS 响应头和 JSON 字段回显接口。
- 通过 `ipwho.is/<实测 IP>` 查询地域，同一 IP 共用 7 天缓存。允许的国家和地区由用户选择，预置美国、日本、新加坡、中国台湾、中国大陆、中国香港，连续两次确认越界后告警。

### 界面与性能

- 出口模块始终显示各目标行。每个目标的详情独立展开/收起，默认收起；关闭弹窗后重置，后台采样不受影响。
- 顶部检查时间靠右，立即复测与复制诊断按钮等宽铺满。
- 取消弹窗动画，重复打开复用视图，按需创建目标历史详情，减少菜单栏打开延迟。

### 验证与安装

本机 466 个默认离线测试及 6 个可选渲染测试通过，已验证安装版本的目标独立折叠交互。发布流程再次执行离线测试并校验应用版本与签名。

ZIP 包包含使用 ad-hoc 签名的 `TunCanary.app`，要求 macOS 13 或更高版本；包名注明构建架构。解压后将应用放入 `~/Applications` 或 `/Applications`。可选 DNS 守护进程继续通过源码仓库中的安装脚本安装。

地域查询依赖第三方服务及本机网络。本机实测仍有地域服务 TLS 连接失败；无法查询时显示地域未知，地域告警不会以未知信息判断越界。两次采样之间的短暂 IP 变化可能未被观察到。

## English

- Automatic exit IP monitoring with a configurable 5–1440 minute interval, staggered targets, shared manual cooldown, rate-limit backoff and sleep/network-change pauses.
- Per-target IPv4/IPv6 history, change and failure counts, retained locally for 30 days. Custom targets support Cloudflare trace, HTTPS response headers and JSON fields; a ByteDance HEAD endpoint is built in.
- Location lookup for the measured IP, shared 7-day cache, selectable allowed regions and alerts after two confirmed out-of-region samples.
- Independent, initially collapsed target details; wider header layout and faster popover opening.
- Requires macOS 13+. The ZIP contains an ad-hoc signed app and names its build architecture. Location lookup can be unavailable on some networks; unknown locations do not trigger region alerts. Changes between samples can be missed.
